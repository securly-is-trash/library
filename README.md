## 5. Universal Library Consolidation

This inventory is intended to be the starting reference for a future universal library.

### Recommended source record

Each imported asset should retain:

- `asset_id` — unique internal identifier
- `title` — original asset title
- `source_url` — original working asset URL
- `source_host` — original hostname
- `github_owner` — repository owner, if applicable
- `github_repo` — inferred or verified repository name
- `source_path` — original path within the source
- `category` — asset category
- `format` — file or asset format
- `status` — availability or import status
- `duplicate_of` — reference to a canonical copy, if duplicated

### Consolidation goals

1. Build a unified index of all 1,128 reported assets.
2. Preserve original source URLs and attribution.
3. Normalize GitHub repository references.
4. Detect duplicate assets across sources.
5. Validate links before importing.
6. Track missing, moved, or inaccessible assets.
7. Provide a consistent retrieval structure for the universal library.
